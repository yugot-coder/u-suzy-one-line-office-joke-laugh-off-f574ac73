One original one-line office joke, written to get the biggest laugh from a
judge that compares jokes two at a time. The line takes a very specific,
very familiar office horror — the ancient yoghurt nobody dares throw away
in the shared fridge — and promotes it to the longest-serving employee.
One read, one twist, no setup to explain.

> There's a yoghurt in the shared fridge from 2019 — it's now technically our longest-serving employee.

## Run it

```sh
python3 main.py
```

This writes the joke to `entry.txt` (and to `/output/entry.txt` when that
directory exists), verifies the write by reading it back byte-for-byte, and
prints its sha256.
